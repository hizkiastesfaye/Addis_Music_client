# Addis_Music_client

The frontend of the Addis Music Management Full-Stack Application is built with React.js and TypeScript. It provides an intuitive and responsive interface for users to manage and visualize their music collection. The frontend communicates seamlessly with the backend REST API to perform CRUD operations and display statistical insights.

Features
User-Friendly Interface: Allows users to add, update, delete, and view songs.
Real-Time Updates: Ensures the UI reflects changes without refreshing the page.
Statistics Display: Visualizes data about songs, artists, albums, and genres.
Modern Styling: Styled using Emotion and Styled System for a clean and responsive design.
State Management: Powered by Redux Toolkit and Redux-Saga for robust and scalable state handling.
